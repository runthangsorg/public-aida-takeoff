# Aida Takeoff

Tender drawings in; quantities and a priced bill of quantities out.

- Reads PDF drawings for one package at a time (MEP counts first), counts and measures with deterministic vector-text extraction plus a vision model for untagged symbols, and exports a structured bill of quantities.
- No drawings are stored in this repository except synthetic fixtures generated by our own scripts. Benchmarks and customer files live elsewhere.

## Development

Requires Node 24 (`.node-version`, `mise.toml`) and, for page rendering, `pdftoppm` from poppler.

```sh
npm ci
npm run check      # typecheck, lint (max-warnings 0), tests
npm run build      # emits dist/
```

`tests/policy.test.ts` fails the build if any tracked file contains an email address, a personal or employer name, a cloud project id, a key-shaped string, or a PDF outside `tests/fixtures/`. CI also runs gitleaks from a checksum-verified binary over the full history.
